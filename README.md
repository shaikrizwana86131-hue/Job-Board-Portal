# CareerConnect – Job Board Portal

## Project Overview
CareerConnect is a responsive Job Board Portal developed using HTML, CSS, and JavaScript.

The website allows users to explore job opportunities, search and filter jobs, and submit a demo job application. It also includes an Admin Dashboard to manage job listings.

## Features
- Responsive website design
- Job listings with company, location, and salary
- Search jobs by role
- Filter jobs by location
- Job application form with validation
- Selected job display on application page
- Admin Dashboard to add and delete jobs
- Local Storage integration
- Dynamic job listings using JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Explore the available jobs.
5. Use the Admin Dashboard to add or delete jobs.

## Project Pages
1. Home Page – Displays available job opportunities.
2. Application Page – Contains the validated application form.
3. Admin Dashboard – Allows adding and deleting jobs.

## JavaScript Mentor Challenge
Implemented dynamic job filtering by role and location using JavaScript without a backend.

## Limitations
- This is a frontend demonstration project.
- Job listings added through Admin are stored in the current browser's Local Storage.
- The Admin Dashboard does not have authentication.
- Applications are not sent to employers.
- Uploaded resumes are not stored.
